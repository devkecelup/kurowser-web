# Kurowser Download Portal

Website resmi distribusi Kurowser (`KurowserSetup.exe` Windows Installer `2.79 MB` dan `kurowser.exe` Portabel `1.89 MB`) yang di-host terpisah dari repositori source code browser.

- Portal Resmi (GitHub Pages): https://devkecelup.github.io/kurowser-web/
- Source Code dan Releases Kurowser: https://github.com/devkecelup/kurowser
- Stack antarmuka: HTML5, CSS3, Vanilla JS, palet **Graphite** dan **Paper** dengan aksen **Teal**, serta font self-hosted **Poppins** (`assets/fonts/`) dan **Cascadia Mono** agar selaras dengan antarmuka aplikasi Kurowser v1.1.4.
- Arah desain: [`DESIGN.md`](DESIGN.md)
