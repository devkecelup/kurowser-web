01 Arsitektur

Empat komponen utama di balik Kurowser.

Setiap bagian berfokus pada tata letak tab yang ringkas, pengurangan proses aktif di memori, serta isolasi halaman internal.

01

Tab Folders, rail 50px, dan topbar tengah

Kelompokkan tab ke dalam folder berwarna (Teal, Sky, Emerald, Amber, Slate, Rose), ubah nama langsung di sidebar (Enter simpan, Esc batal), dan pindahkan tab via drag and drop. Secara bawaan sidebar menyusut rapi menjadi rail 50px dan otomatis melebar ke 240px saat hover (atau sematkan dengan Ctrl + B), sementara bilah pencarian, Kurowser Shields, dan bookmark terpasang stabil di tengah topbar 42px.

02

Kurowser Shields

Aktif secara bawaan. Domain iklan, pelacak, telemetri, dan popunder dicegat di WebResourceRequested sebelum keluar ke jaringan, disertai cosmetic CSS hiding, penghapus payload iklan YouTube (/youtubei/v1/), dan allowlist berbasis hash bergaram BCryptGenRandom.

03

Batas renderer LRU dan Hemat RAM

Hanya mempertahankan 2 sampai 4 renderer WebView2 aktif secara bersamaan (bawaan 3). Tab paling lama tidak dipakai dilepas sambil menyimpan URL dan ikon cache, ditambah tombol Hemat RAM untuk menurunkan level memori renderer aktif.

04

Skema kurowser:// tanpa localhost

Seluruh halaman internal dilayani langsung dari memori melalui ICoreWebView2CustomSchemeRegistration tanpa membuka port TCP lokal, dilengkapi token BCryptGenRandom, per-page CSP nonce, pemeriksaan constant-time, dan blokir iframe lintas origin.

02 Perbandingan

Jejak terukur dan perbandingan arsitektur.

Ukuran paket diambil langsung dari berkas rilis Kurowser v1.1.3, sedangkan baseline memori diukur dengan measure_memory.ps1 pada v1.0.0. Perbandingan antar browser membahas arsitektur engine dan fitur secara faktual tanpa mencantumkan angka RAM tebakan.

Jejak memori baseline Kurowser pada kurowser://start (MB)

Satuan MB Windows (1024 x 1024 byte). Nilai lebih kecil berarti jejak lebih hemat.

Memuat metrik terukur...

Baseline diukur langsung di Windows memakai measure_memory.ps1 pada sesi bersih kurowser://start (v1.0.0): proses host kurowser.exe memakan 6.47 MB Private (34.86 MB Working Set) dan total pohon bersama 6 sub-proses msedgewebview2 sebesar 185.87 MB Private (386.74 MB Working Set).

03 Unduh

Dua paket unduhan untuk Windows x64.

Pilih installer per-user untuk pemasangan dengan shortcut, atau berkas portabel tunggal untuk langsung dijalankan.

Installer

Disarankan

Pemasangan lengkap per-user tanpa prompt UAC, disertai shortcut, auto-updater, dan uninstaller native.

  • Dipasang ke %LOCALAPPDATA%\Programs\Kurowser (mendukung flag --silent, --preserve-shortcuts, --wait-pid, dan --uninstall).
  • Membuat shortcut Start Menu, opsi shortcut Desktop, dan entri App Paths untuk Win+R.
  • Mendukung pembaruan otomatis terverifikasi SHA-256 serta terdaftar di Windows Apps & Features.

Portabel

Satu berkas binary yang bisa dijalankan langsung dari folder mana saja tanpa menulis ke registry.

  • Jalankan kurowser.exe secara langsung tanpa proses setup maupun shortcut sistem.
  • Mendukung pembaruan otomatis portabel terverifikasi SHA-256 dari GitHub Releases.
  • Pengaturan, bookmark, dan folder tab tetap disimpan rapi di %LOCALAPPDATA%\Kurowser.
