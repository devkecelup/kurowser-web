01 Arsitektur

Empat bagian yang menentukan berat dan privasi.

Setiap bagian punya satu tugas: memangkas memori, menutup jalur pelacakan, atau menjaga halaman internal tetap lokal.

01

Tab folder di sidebar

Kelompokkan tab ke folder berwarna, ubah nama langsung di sidebar, pindahkan antar folder dengan drag-and-drop, buka context menu, dan lipat folder yang tidak sedang dipakai. Isi folder disimpan ke folders.json dan baru dimuat saat diklik, jadi 0 MB RAM sampai folder dibuka.

02

Kurowser Shields

Aktif secara default. Domain iklan, tracker, telemetry, dan popunder diblokir di level jaringan WebView2 sebelum request terkirim, ditambah penyembunyian elemen iklan kosmetik dan toggle per situs.

03

Batas RAM LRU

Renderer aktif dibatasi 2 sampai 4 tab (default 3). Tab yang paling lama tidak dipakai ditidurkan, lalu dimuat lagi saat dibuka. Untuk laptop 4 sampai 8 GB dan sesi gaming.

04

Tanpa server localhost

Halaman internal dilayani dari memori lewat custom scheme WebView2, dengan token sesi BCryptGenRandom, CSP nonce per halaman, dan proteksi navigasi lintas origin. Tidak ada port lokal yang terbuka.

03 Unduh

Dua cara menjalankan Kurowser.

Installer per-user untuk pemakaian harian, atau satu file portable tanpa instalasi. Keduanya untuk Windows x64.

Installer

Disarankan

Pemasangan lengkap tanpa prompt UAC, dengan shortcut dan uninstaller.

  • Dipasang per-user ke %LOCALAPPDATA%\Programs\Kurowser.
  • Shortcut Start Menu dan Desktop opsional, bisa dijalankan lewat Win+R dengan perintah kurowser.
  • Terdaftar di Windows Apps & Features dengan uninstaller bawaan.

Portable

Satu file untuk flashdisk atau folder proyek, tanpa mengubah shortcut dan registry.

  • Klik dua kali pada kurowser.exe untuk langsung menjalankan browser.
  • Tidak memasang layanan, driver, atau entri startup.
  • Profil dan folder tab tetap tersimpan di %LOCALAPPDATA%\Kurowser.
