Arsitektur & Fitur

Dirancang Ringan Tanpa Mengorbankan Kenyamanan

Setiap komponen dibangun ulang dengan fokus performa, privasi jaringan, dan kerapian ruang kerja Anda.

Tab Folders & Sidebar Vertikal

Kelompokkan tab ke dalam folder berwarna kustom lengkap dengan inline rename, drag-and-drop antar folder, collapse/expand, context menu, dan penyimpanan otomatis ke folders.json (lazy-load 0 MB RAM hingga diklik).

Kurowser Shields (Ad & Tracker Blocker)

Aktif secara default untuk memblokir domain iklan, tracker, telemetry, dan popunder langsung di level jaringan WebView2 sebelum request terkirim, ditambah penyembunyian elemen iklan kosmetik (CSS) dan toggle per-situs.

LRU RAM Cap & Tombol Hemat RAM

Membatasi renderer aktif hanya 2–4 tab (default 3). Tab yang paling lama tidak dipakai otomatis ditidurkan dan dimuat kembali seketika saat dibuka, menjaga laptop 4–8 GB atau sesi gaming tetap mulus.

Zero Localhost (kurowser:// COM Isolation)

Seluruh halaman internal dilayani langsung dari memori melalui Custom Scheme WebView2 dengan BCryptGenRandom session token, per-page CSP nonce, dan proteksi navigasi lintas-origin. Tidak ada port lokal yang diekspos.

Benchmark & Matriks

Perbandingan RAM, Ukuran, dan Fitur

Bandingkan efisiensi memori, ukuran distribusi, serta kelengkapan fitur Kurowser dengan browser desktop populer lainnya di Windows x64.

Private RAM — 4 Tab Aktif incl. GitHub + Settings (MB, Lebih Kecil Lebih Hemat)

Data Kurowser Start (171.7 MB Private) dan Kurowser 4 Tab incl. GitHub + Settings + LRU Cap 3/3 (498.7 MB Private, Rust host 7.5 MB) diukur langsung pada Windows 11 x64 menggunakan measure_memory.ps1. Angka browser lain merupakan baseline estimasi umum Windows x64 tanpa LRU Cap ketat.

Pilih Format Unduhan Windows x64

Tersedia installer native tanpa UAC untuk pemasangan lengkap di Start Menu & Apps, atau versi portable satu file siap jalan.

Kurowser Installer (Disarankan)

KurowserSetup.exe · 2.58 MiB (2,709,504 bytes)
Windows Installer
  • Pemasangan per-user ke %LOCALAPPDATA%\Programs\Kurowser tanpa prompt UAC.
  • Membuat shortcut Start Menu, Desktop (opsional), dan dukungan run via Win+R (kurowser).
  • Terdaftar rapi di Windows Apps & Features dengan uninstaller bawaan.
